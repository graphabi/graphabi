# GraphABI v0.1.0-alpha.1

GraphABI's first public alpha demonstrates a narrow, deterministic claim: two agent-graph
versions can share one Pydantic model and compatible JSON schema while violating the meaning a
downstream consumer relies on. GraphABI identifies the first breaking edge, preserves a recorded
counterexample, and calculates affected terminal paths.

## Included

- Consumer-driven, versioned YAML contracts validated through Pydantic.
- Deterministic implication, provenance, preservation/completeness, unit, authority, and freshness
  evaluators with explicit uncertainty states.
- A framework-independent trace schema with LangGraph instrumentation, SQLite storage, and JSON /
  JSONL interchange.
- Structural and semantic comparison with stable findings, minimized witnesses, and NetworkX
  downstream impact analysis.
- Offline JSON and self-contained HTML reports generated from persisted traces.
- Conservative contract suggestions that remain `SUGGESTED: NOT ENFORCED`.
- A no-key deterministic demo, CLI, 10/100/1,000-node local benchmark, and extension interfaces.

## Demonstration result

The bundled research graph produces structurally compatible baseline and candidate outputs. The
candidate intentionally claims verification after source access fails. GraphABI reports semantic
`FAIL` at `researcher -> verifier`, includes the `candidate-003` witness, and shows the affected
path through `verifier`, `decision_maker`, and terminal `publisher`.

## Safety and audit work

The alpha includes adversarial coverage for wrong-graph observations, duplicate trace identities,
unit and authority regressions, branching/cyclic impact analysis, malformed contracts, corrupt
SQLite rows, report escaping, secret-shaped masking, and stable CLI exit codes. The hostile audit
and corrections are recorded in [`AUDIT.md`](../../AUDIT.md).

## Known limits

GraphABI enforces explicit assumptions over observed executions; it does not understand arbitrary
meaning or prove behavior for unseen inputs. LangGraph is the only maintained adapter. SQLite is a
local single-process store, masking is not general DLP, and conservative unit conversion remains
unproven unless an application supplies a verified policy. See
[`docs/limitations.md`](../limitations.md) before adopting the alpha.

## Install after release

PyPI publication is intentionally not part of this release. Build and install the reviewed wheel
from a checkout:

```bash
uv build
uv tool install dist/graphabi-0.1.0a1-py3-none-any.whl
graphabi demo --allow-breaking
```

The release should be published only after the repository is public, CI passes on `main`, the tag
matches the reviewed commit, and a maintainer approves these notes.
